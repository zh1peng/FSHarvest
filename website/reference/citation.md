# 引用与许可证

## 引用 FSHarvest

仓库根目录的 `CITATION.cff` 提供机器可读的软件引用信息。GitHub 可以据此生成引用文本。

当前软件元数据：

```text
Title: FSHarvest
Version: 1.0.0rc1
Status: release candidate; no stable release date
Code license: MIT; bundled atlas resources retain their upstream licenses
```

## Atlas 引用

使用外部 Atlas 时，还应引用相应的原始论文。固定来源、commit、DOI、模板和重新分发许可证记录在：

- [`atlases/README.md`](https://github.com/zh1peng/FSHarvest/blob/main/atlases/README.md)
- [`THIRD_PARTY_NOTICES.md`](https://github.com/zh1peng/FSHarvest/blob/main/THIRD_PARTY_NOTICES.md)

## 许可证边界

FSHarvest 源代码采用 MIT 许可证。Bundled `.annot` 文件继续受其上游许可证约束；
软件许可证不会替代 Atlas 作者要求的科学引用与数据使用条款。
