# Harvest analysis-ready FreeSurfer features

FSHarvest is a Linux command-line tool for extracting cortical, subcortical, global,
Euler, provenance, and optional surface-QC data from cohorts of FreeSurfer subjects.

## English documentation

The English documentation is under development. The Chinese documentation is the
current complete reference.

- [Read the Chinese documentation](/)
- [Open the GitHub repository](https://github.com/zh1peng/FSHarvest)

```bash
fsharvest /path/to/subjects /path/to/output --jobs 12
```
