# Batch extraction of FreeSurfer regional measures

FSHarvest is a Linux command-line tool that reads completed FreeSurfer subject directories
and produces cohort-level cortical, subcortical, global, Euler-number, provenance, and
optional surface-QC outputs. Inputs remain unchanged unless export is explicitly enabled.

## English summary

The full documentation is currently available in Chinese. This page provides the command
needed to get started; an expanded English reference is planned.

```bash
fsharvest /path/to/subjects /path/to/output --jobs 12
```
